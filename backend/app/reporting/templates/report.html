Methodology

Pipeline. Uploaded exports are validated, mapped to a canonical schema (automatic fuzzy column matching with confidence scores and manual review), and normalized. All metrics, comparisons and findings are computed by the analytics engine before any AI step; the AI layer only interprets these verified results.

Metrics. Engagement = likes + comments + shares + saves (components a platform does not report are excluded, not zero-filled). Engagement rate = engagement / exposure × 100, where exposure is reach (Instagram, Facebook), views (TikTok) or impressions (LinkedIn). Share/save/comment rates use the same denominator; CTR = clicks / impressions × 100.

Statistics. Group comparisons use Mann-Whitney U (rank-biserial effect size) and Kruskal-Wallis (epsilon²), which are robust to the skew of social metrics. Relationships use Spearman correlation; a log-linear OLS model estimates format/pillar effects while controlling for each other. Trends use the Theil-Sen slope on weekly medians. P-values are adjusted for multiple testing with Benjamini-Hochberg (FDR {{ run.parameters.alpha }}). Tests are only run with at least {{ run.parameters.min_test_group_size }} posts per group.

Confidence. High / medium / low confidence combines sample size (≥30 / 10-29 / <10), adjusted significance, effect size and data completeness.
